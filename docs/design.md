# easy-log-packet-analyzer 설계 문서 (초안)

> 이 도구가 왜 필요한지: [why.md](why.md)

목표: 로그 파일과 패킷 파일(pcap)을 한 도구로 쉽게 보는 Python 프로그램. 입문자도 이해할 수 있게, 실용 기능부터.
이 문서는 설계만 담습니다. 코드는 없습니다.

## 용어
- CLI: 명령줄에서 쓰는 프로그램.
- 파서: 글자나 바이트를 읽어 구조(필드)로 바꾸는 코드.
- 레코드: 로그 한 줄 또는 패킷 하나를 정리한 데이터 한 건.

## 전체 구조 (Wireshark에서 가져옴)
입력 → 파싱 → 해석 → 표시. 로그와 패킷 모두 같은 "레코드" 형태로 바꿔서 뒤쪽 단계를 같이 씁니다.

레코드 공통 필드: 시간, 출발지, 목적지, 종류(로그/프로토콜), 요약, 원본.

## 단계
### 1단계: 로그 파일 읽기
- 텍스트 로그(예: Apache access log, auth.log)를 한 줄씩 읽어 정규식(글자 패턴 규칙)으로 시간·IP·메시지를 뽑습니다.
- 결과를 표로 출력.

### 2단계: pcap 읽기 (scapy / pyshark)
- scapy: 순수 Python 패킷 라이브러리. 설치 쉬움. 먼저 사용.
- pyshark: tshark를 불러 쓰는 라이브러리. 해석 프로토콜이 많지만 tshark 설치 필요. 나중에 선택 옵션.
- 패킷마다 시간, IP, 포트, 프로토콜을 레코드로 변환.

### 3단계: 필터
- `ip=1.2.3.4`, `port=22`, `text=Failed` 같은 단순 조건만 지원.

### 4단계: 통계
- 상위 출발지 IP, 프로토콜별 개수, 시간대별 개수.

### 5단계: 경고 (Expert Info 단순 버전)
- 예: 같은 IP의 로그인 실패 반복, 짧은 시간 많은 포트 접속(포트 스캔 의심). 쉬운 한국어 문장으로 출력.

### 6단계: 출력 형식
- 표(기본), CSV, JSON.

### 7단계 (나중): 로그와 패킷 시간순 합쳐 보기
- 같은 IP 기준으로 로그와 패킷을 한 화면에.

## 하지 않을 것 (초기)
- 실시간 캡처, GUI, 프로토콜 직접 해석, 복잡한 필터 문법.

## 샘플 데이터 (공개 자료만)
- Wireshark SampleCaptures: https://wiki.wireshark.org/SampleCaptures
- 로그 샘플: 공개 데이터셋(예: https://github.com/logpai/loghub) 사용. 개인/회사 데이터는 넣지 않음.
